# BeautyCart

A responsive BeautyCart e-commerce storefront recreated from the supplied design reference.

## Included
- Premium header/search/navigation
- Responsive hero carousel
- Product catalogue with search + category filters
- Wishlist with localStorage
- Functional cart drawer with quantity controls
- Product detail modal
- Offers, categories, membership promo
- Responsive mobile/tablet layout
- No build step required

## Run
Open `index.html` in a modern browser.

Product/hero images use remote Unsplash image URLs, so an internet connection is needed for those images. Replace the image URLs in `script.js` if you want local assets.

## Next integration points
- Replace demo product data in `script.js` with API/database data.
- Connect checkout button to Razorpay/Stripe or your backend.
- Add authentication and real user profile.
- Add product detail routes and backend orders.
